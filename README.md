# 生成

DSH 插件：使用 DSH 中配置的模型路线生成图片或视频，并将结果保存到本地。

## 设置

在插件详情页分别选择默认图片和视频模型，并设置比例、图片质量、视频分辨率、时长和保存目录。列表读取当前 DSH 的提供方和模型，可自行选择模型；是否支持生成由实际提供方和调用结果决定。配置变更后点击保存。

参数提供常用选项，并补充所选路线目录中的其他选项。可自行选择默认参数；选项出现不代表提供方一定支持，实际结果由提供方决定。选择自动或留空时不向适配器传递该参数。

图片和视频可分别设置一个兜底模型。明确的上游失败或返回无效媒体时，插件最多尝试一次所选兜底；用户取消、本地权限、输入参数或保存失败时不再生成。上游生成可能仍在运行且状态不明时，不自动切换兜底，避免重复生成。两次都失败时会显示两次的失败阶段。

对话中明确指定的参数优先于插件设置。调用时提供方和模型共同确定路线；仅在符合兜底条件时切换到明确配置的兜底路线。未选择对应类型的模型时，调用会提示先设置。留空保存目录时使用会话工作目录，没有工作目录时使用下载目录。

对话中没有明确要求分辨率时，使用已保存的默认分辨率；选择“自动”时不发送分辨率。提供方是否支持该值以实际调用为准。

旧版本的设置会作为 `legacySettings` 保留，比例、质量、分辨率、时长和目录继续使用；旧的 Grok/GPT 模型不会自动映射到不等价的 DSH 路线，请重新选择图片和视频模型。

多个 Host 共享同一 `DSH_HOME` 时会读取同一份设置；如果其他窗口先保存了更改，本窗口保存时会提示刷新，避免覆盖。旧设置不完整或损坏时会保留原文件并报告错误。

## 运行条件

需要支持 `generateMedia` 的 DSH Host、对应提供方的已配置账号或凭据、以及可用的 FFmpeg。实际支持的模型和参数由所选 Host 适配器与远端服务决定；聊天模型存在或支持图片输入不代表支持生成。图片或视频生成可能产生服务费用。

插件在调用前检查输出权限，下载远端结果时只接受安全的 HTTPS 地址，使用 FFmpeg 检查媒体后再保存；失败或取消不会覆盖既有文件。参考图片也会经过大小与格式检查。

图片和视频每次尝试均使用 600 秒的总超时，覆盖生成、下载和验证；配置兜底时最多尝试两次，可能共用 1200 秒。媒体解码另有 60 秒上限。

## 验证

本仓库的测试使用 Node 测试运行器；涉及 DSH 文件权限的测试需要提供官方 SDK 的 `DSH_OFFICIAL_ROOT`。本地 mock 测试不能证明具体远端账号和模型可用。

跨模块集成测试需要已安装依赖的 DSH 源码。先在 shell 中导出指向源码的 `DSH_HOST_SOURCE_ROOT`，再运行 `"$DSH_HOST_SOURCE_ROOT/node_modules/.bin/vitest" run --config test/host-vitest.config.mjs`。未设置时测试会明确报错。
